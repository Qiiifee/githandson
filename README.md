# GitReady 2.0

Website project untuk Study Case GitReady 2.0 yang mensimulasikan workflow kolaborasi developer menggunakan Git dan GitHub.

## Visualisasi

Buka `index.html` menggunakan browser untuk melihat website.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Fitur Utama

- Responsive landing page
- Navigation menu
- Hero section
- Team workflow section
- Interactive JavaScript buttons
- Smooth scrolling
- Mobile-friendly layout

## Contribution

### Anggota 1 — Project Initiator
- Membuat repository GitHub
- Mengatur collaborator
- Menyiapkan struktur awal project
- Mengelola branch utama

### Anggota 2 — Styling Engineer
- Membuat dan mengembangkan `style.css`
- Mendesain layout dan responsive design
- Menghubungkan stylesheet dengan `index.html`

### Anggota 3 — Script Engineer
- Membuat `script.js`
- Menambahkan interaksi website
- Menghubungkan JavaScript dengan `index.html`

> Ganti nama anggota dan username GitHub sesuai anggota kelompok sebelum submission.

## What I Learned

Melalui project ini, kami belajar bagaimana menggunakan Git dan GitHub untuk bekerja secara kolaboratif. Kami belajar membuat branch, melakukan commit dan push, membuat Pull Request, melakukan code review, serta memahami cara menyelesaikan conflict ketika beberapa anggota mengubah file yang sama.
